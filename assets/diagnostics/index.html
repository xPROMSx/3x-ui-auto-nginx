04 Check from Windows
Use WinMTR for the reverse direction: your computer → this server.

      
  1. Download WinMTR from GitHub and open WinMTR.exe.
  2. For Host, enter __SERVER_DOMAIN__ or __SERVER_IP__.
  3. Set Max hosts to 30 and Interval to 1000 ms.
  4. Run for at least 300 packets (around 5 minutes), then select Export TEXT.
