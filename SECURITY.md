# Security policy

Security fixes are maintained for the current release line of **3x-ui Auto Nginx**. Before reporting, check whether the issue still applies to current `main` or the latest project release.

Please report auth bypass, RCE, injection, secret exposure, privilege escalation and similar vulnerabilities through [GitHub Private Vulnerability Reporting](https://github.com/xPROMSx/3x-ui-auto-nginx/security/advisories/new). Do not publish exploit details in ordinary Issues. If private reporting is unavailable, arrange a private channel with the maintainer before sharing sensitive details.

Ordinary bugs without sensitive security details can be reported in [Issues](https://github.com/xPROMSx/3x-ui-auto-nginx/issues).
