# Первый запуск

Это краткий маршрут для новой установки. Полное описание всех вопросов и вариантов есть в [README проекта](https://github.com/xPROMSx/3x-ui-auto-nginx#quick-start).

## Что понадобится

- **Чистый VPS** с Ubuntu 24.04, Ubuntu 26.04 или Debian 13.
- Доступ к серверу по **SSH от root**.
- **Два домена или поддомена** с DNS-записями на IP нового VPS: для панели и для REALITY.
- Открытые входящие порты TCP 80, TCP 443 и UDP 443. Для дополнительного DNS-over-TLS потребуется TCP 853.

!!! danger "Команда ниже запускает установщик"
    На сервере с установленным стеком пункт **«Установка»** после подтверждения заменит базу 3x-ui и конфигурацию nginx. Перед переустановкой сохраните Backup **вне VPS**. Для смены доменов, резервного копирования и восстановления используйте соответствующие пункты менеджера.

## Команда

Выполните в интерактивном SSH-терминале на **своём чистом VPS** под пользователем **root**.

```bash
curl -fSL https://github.com/xPROMSx/3x-ui-auto-nginx/releases/latest/download/x-ui-latest.sh -o x-ui-latest.sh && bash x-ui-latest.sh
```

В меню выберите **2 — Русский**, затем **1 — Установка** и ответьте на вопросы. При успешной установке вы получите адрес панели. Если вы выбрали создание клиента, установщик также покажет ссылку на подписку.
