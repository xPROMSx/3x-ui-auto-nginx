# 3X-UI AUTO NGINX

## Свой прокси-сервер с понятной настройкой

3X-UI AUTO NGINX устанавливает на твой VPS панель 3x-ui, Xray и nginx, получает HTTPS-сертификаты, настраивает основные подключения и, по желанию, создаёт клиента со ссылкой подписки.

[Начать установку](start.md){ .md-button .md-button--primary }
[Каталог инструкций](guides/index.md){ .md-button }

!!! warning "Установка не является обновлением"
    На работающем сервере пункт **«Установка»** после подтверждения заменяет управляемые данные. Для смены доменов и восстановления есть отдельные операции. [Что нужно знать перед установкой](start.md).

## От нового VPS до подключения

<div class="grid cards guide-cards" markdown>

-   :material-server:{ .lg .middle } **01 · Подготовь VPS**

    Чистая Ubuntu 24.04/26.04 или Debian 13, доступ по SSH и открытые необходимые порты.

-   :material-web:{ .lg .middle } **02 · Настрой домены**

    Один домен для панели и подписок, второй для REALITY. Укажи IP своего VPS в DNS.

-   :material-rocket-launch:{ .lg .middle } **03 · Запусти установщик**

    Ответь на семь вопросов. В руководстве поясняем каждую настройку и её значение по умолчанию.

-   :material-link-variant:{ .lg .middle } **04 · Подключи устройство**

    Добавь ссылку подписки в подходящее приложение и проверь, что трафик идёт через VPS.

</div>

[Подробная инструкция с пояснениями](start.md){ .md-button .md-button--primary }

## Возможности проекта

<div class="grid cards guide-cards" markdown>

-   :material-lan:{ .lg .middle } **Основные подключения**

    REALITY, XHTTP и Hysteria2 устанавливаются по умолчанию. Дополнительные протоколы выбираются отдельно.

-   :material-shield-check:{ .lg .middle } **Защита и личный DNS**

    Fail2ban, обновления безопасности, шифрованный DNS сервера и, при желании, AdGuard Home.

-   :material-source-branch:{ .lg .middle } **Каскад из двух серверов**

    Входной VPS принимает подключения, а выходной становится точкой выхода в интернет.

    [Пошаговая настройка каскада](guides/cascade.md)

-   :material-backup-restore:{ .lg .middle } **Резервные копии и смена доменов**

    Создавай Backup, восстанавливай сервер и меняй домены из меню без ручного изменения nginx.

</div>
