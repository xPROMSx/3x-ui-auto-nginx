# 3X-UI AUTO NGINX

## Свой прокси-сервер на 3x-ui и Xray

Установщик настраивает 3x-ui, Xray и nginx на вашем VPS. В конце установки вы получите адрес панели, а если выбрали создание клиента — ссылку на подписку.

[Начать работу](start.md){ .md-button .md-button--primary }
[Каталог инструкций](guides/index.md){ .md-button }

---

## Что умеет проект

<div class="grid cards" markdown>

- :material-rocket-launch:{ .lg .middle } **Установка из меню**

    ---

    Установщик получает TLS-сертификаты и настраивает nginx и панель 3x-ui. Сертификаты продлеваются автоматически.

- :material-lan:{ .lg .middle } **Несколько способов подключения**

    ---

    По умолчанию доступны REALITY, XHTTP и Hysteria2. Дополнительные профили включаются при необходимости.

- :material-web:{ .lg .middle } **Сайты-прикрытия**

    ---

    На доменах панели и REALITY открываются многостраничные сайты. Неавторизованные запросы по HTTP/3 на домене REALITY получают тот же сайт, что и обычные HTTPS-запросы.

- :material-source-branch:{ .lg .middle } **Каскад из двух VPS**

    ---

    Соедините два VPS из меню и направляйте часть трафика через выходной сервер.

- :material-shield-check:{ .lg .middle } **Защита и личный DNS**

    ---

    Панель и подписки доступны по HTTPS. При установке можно включить защиту SSH и автоматические обновления VPS, а также установить AdGuard Home с DoH и опциональным DoT.

- :material-backup-restore:{ .lg .middle } **Переезд с сохранением клиентов**

    ---

    Перенесите весь стек через Backup / Restore или восстановите только клиентов и данные подписок. При сохранении домена панели прежние ссылки на подписки можно сохранить.

</div>

## С чего начать

1. Подготовьте чистый VPS с Ubuntu 24.04, Ubuntu 26.04 или Debian 13, доступ по SSH и два домена.
2. Выполните шаги из раздела [«Первый запуск»](start.md) и ответьте на вопросы установщика.
3. Если создали клиента при установке, добавьте полученную подписку в совместимое приложение.
