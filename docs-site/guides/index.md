# Гайды и инструкции

Здесь собраны пошаговые руководства по установке, защите и обслуживанию своего VPS. Для удобного поиска они расположены **по русскому алфавиту**. Все основные инструкции доступны прямо на сайте.

**Новый сервер?** Начни с отдельного руководства: оно проведёт от подготовки VPS до первого рабочего подключения.

[Первый запуск: пошаговая установка](../start.md){ .md-button .md-button--primary }

## Все руководства по алфавиту

<div class="grid cards guide-cards" markdown>

-   :material-shield-check:{ .lg .middle } **Безопасность VPS**

    Сетевой экран UFW, Fail2ban, защищённый DNS, автоматические обновления nginx и ядра, расписание и проверка результата.

    [Настроить защиту сервера](security.md)

-   :material-source-branch:{ .lg .middle } **Каскад из двух VPS**

    Соединение входного и выходного серверов, маршрутизация трафика, проверка работы и отключение каскада.

    [Настроить каскад](cascade.md)

-   :material-key-variant:{ .lg .middle } **Ключи SSH**

    Создание ключа на Windows 11, добавление на Ubuntu 24.04/26.04 и проверка входа без пароля учётной записи.

    [Добавить SSH-ключ](ssh-keys.md)

-   :material-shield-lock:{ .lg .middle } **Личный DNS**

    AdGuard Home, блокировка рекламы, DNS-over-HTTPS, ClientID и частный DNS на Android.

    [Настроить AdGuard Home и DNS](dns.md)

-   :material-lan:{ .lg .middle } **Подключения и nginx**

    REALITY, XHTTP, Hysteria2, дополнительные протоколы, личные подписки и автоматические HTTPS-сертификаты.

    [Разобраться в подключениях](connections.md)

-   :material-backup-restore:{ .lg .middle } **Резервные копии и клиенты**

    Полный Backup и восстановление работающего сервера у другого хостера. Перенос клиентов и сохранение путей подписок в свежую установку.

    [Backup, Restore и перенос клиентов](backup.md)

-   :material-web:{ .lg .middle } **Смена доменов**

    Замена доменов панели и REALITY без переустановки, с сохранением клиентов и настроек сервера.

    [Поменять домены](domains.md)

</div>
