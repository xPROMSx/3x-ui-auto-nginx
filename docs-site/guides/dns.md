# Личный DNS и AdGuard Home

## Для чего нужен свой DNS-сервер

DNS (система доменных имён) переводит название сайта в IP-адрес. Обычно устройство отправляет такие запросы DNS-провайдеру сети. С помощью **AdGuard Home** ты можешь управлять ими на собственном VPS: видеть обращения устройств, блокировать домены рекламы и отслеживания, создавать свои правила и выбирать вышестоящие DNS-серверы.

3X-UI AUTO NGINX устанавливает и связывает AdGuard Home с уже работающим nginx. Твой DNS получает защищённый HTTPS-адрес на домене панели, а управление доступно через отдельную веб-панель. Никакого дополнительного домена не требуется.

### Две разные DNS-функции установщика

| Функция | Для кого работает | Когда включается |
| --- | --- | --- |
| **Шифрованный DNS самого VPS** | Глобальные DNS-запросы сервера через systemd-resolved | При выборе «Расширенная безопасность VPS» |
| **AdGuard Home** | Телефоны, компьютеры и другие устройства, которые ты к нему подключишь | По отдельному вопросу установщика |

Первая функция защищает DNS-запросы самого сервера. Вторая даёт полноценный личный DNS с фильтрацией и журналом запросов устройств.

## 1. Включи AdGuard Home при установке

На вопрос **«Установить и настроить AdGuard Home?»** ответь **Y**. Установщик создаст службу и настройку nginx, выпустит нужные веб-адреса и покажет данные в итоговом отчёте.

Пример адресов (не копируй их буквально):

- Панель AdGuard Home: `https://panel.example.com/adg-.../`
- Защищённый DNS-over-HTTPS (DoH): `https://panel.example.com/dns-XXXXXXXXXXXX`
- DNS-over-TLS (DoT) для устройств, если ты его включишь: имя `panel.example.com`, порт `853`

Реальные адреса и логин показываются **после установки**. Позже их можно посмотреть в главном меню через **«6. Данные моего сервера»**. Пароль AdGuard Home запомни при установке.

Обычный публичный DNS на порту 53 проект не открывает. Для DoH используется nginx и существующий HTTPS-домен панели.

## 2. Настрой фильтрацию рекламы и запросов

1. Открой выданный адрес панели AdGuard Home и войди с сохранёнными учётными данными.
2. В разделе DNS-фильтров выбери подходящие списки блокировки. Списки можно менять и отключать.
3. В журнале запросов проверь, какие домены обращаются к DNS. Если полезный сервис перестал открываться, проверь его запросы и при необходимости разреши конкретный домен.
4. Добавь постоянные клиенты, чтобы различать свои устройства и выбирать для них правила.

DNS-фильтрация блокирует запросы к известным рекламным и отслеживающим доменам. Она также позволяет управлять собственными DNS-правилами. Реклама, загружаемая с домена основного сайта, может оставаться: это свойство самого метода фильтрации.

## 3. Защити DoH с помощью ClientID {#doh-clientid}

**ClientID** - уникальный идентификатор устройства, который добавляется в путь DoH. Он помогает разделять записи разных устройств и ограничивать использование твоего DNS посторонними.

1. В AdGuard Home создай постоянного клиента, например для телефона, и назначь ему длинный индивидуальный ClientID.
2. Перейди в **Настройки → Настройки DNS → Настройки доступа → Разрешённые клиенты** и добавь созданные ClientID.
3. В приложении, которое поддерживает DoH, укажи персональный адрес по шаблону:

```text
https://panel.example.com/dns-XXXXXXXXXXXX/ClientID
```

Здесь `panel.example.com`, случайный путь и `ClientID` нужно заменить собственными значениями. После включения списка разрешённых клиентов запросы без подходящего ClientID отклоняются.

Если используешь DoT для устройств, добавь также `127.0.0.1` в разрешённые клиенты - особенности этой схемы разобраны ниже.

Официальные инструкции AdGuard: [постоянные клиенты и ClientID](https://adguard-dns.io/kb/ru/adguard-home/clients/) и [безопасный запуск](https://adguard-dns.io/kb/ru/adguard-home/running-securely/).

## 4. Подключи устройство по DoH

DoH передаёт DNS-запросы по HTTPS. Его поддерживают многие приложения, системы и сетевые клиенты. В настройках DNS выбранного приложения найди вариант пользовательского DoH-сервера и вставь адрес с ClientID. Название пункта зависит от клиента.

Проверь результат: открой любой сайт на устройстве, затем посмотри **Журнал запросов** в AdGuard Home. Там должны появиться запросы твоего клиента. Если записей нет, приложение может использовать собственный DNS или обходить заданную настройку.

## 5. Частный DNS на Android через DoT

Android поддерживает системный пункт **«Частный DNS»**. В отличие от DoH, он принимает **имя хоста**, а не полный HTTPS-адрес. Чтобы использовать эту функцию:

1. Во время первой установки выбери AdGuard Home, затем ответь **Y** на вопрос о включении DNS-over-TLS для устройств.
2. На Android открой настройки сети и найди **«Частный DNS»** (в зависимости от оболочки пункт может называться иначе).
3. Выбери вариант с именем хоста провайдера и введи **домен панели**, например `panel.example.com`.
4. Сохрани и проверь появление запросов в AdGuard Home.

DoT использует TCP-порт **853**, который установщик открывает в UFW. Все DoT-запросы в журнале AdGuard Home приходят от локального адреса `127.0.0.1`, поскольку проходят через nginx. Поэтому разные Android-устройства по ClientID здесь не различаются.

!!! warning "Доступ к DoT"
    DoT по этой схеме доступен в интернете по домену и порту 853. ClientID в нём не передаётся. Если включить разрешённые клиенты только по ClientID, DoT перестанет отвечать. Для его работы нужно разрешить `127.0.0.1`, что позволит обращаться через DoT любому, кто знает адрес сервера. Для индивидуального разграничения устройств выбирай DoH с ClientID.

Если DoT для устройств больше не нужен, закрой его публичный порт. Подключись к VPS по SSH; если вошёл под обычным пользователем, выполни `sudo -i`. **На VPS от root:**

```bash
ufw delete allow 853/tcp
```

После этого DoT перестанет быть доступен извне; DoH продолжит работать. Правила UFW могут отличаться на VPS с ручной настройкой firewall, поэтому сначала сверяй действующую конфигурацию.

## 6. Как сохраняются настройки

AdGuard Home, его конфигурация, фильтры и данные включаются в **полный Backup v3**. При полном Restore на совместимый VPS они восстанавливаются вместе с управляемым стеком. При смене домена панели проект учитывает сертификат дополнительного DoT.
