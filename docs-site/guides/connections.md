# Подключения, nginx и каскад

## Зачем установщик создаёт несколько подключений

Прокси-сервер работает в разных сетях: дома, у мобильного оператора и через публичный Wi-Fi. Доступность протоколов и качество соединения могут различаться. Поэтому 3X-UI AUTO NGINX сразу подготавливает **три основных варианта подключения** и позволяет добавить другие из меню.

| Подключение | Что знать новичку |
| --- | --- |
| **VLESS REALITY** | Один из основных способов подключения через Xray. Используется отдельный домен REALITY. |
| **VLESS XHTTP** | Передача данных через HTTP-транспорт Xray, интегрированный с маршрутизацией сервера. |
| **Hysteria2** | Подключение по UDP/443, работающее по HTTP/3. Может хорошо работать там, где доступен UDP. |

**REALITY, XHTTP и Hysteria2 устанавливаются по умолчанию.** Не нужно включать все дополнительные варианты, чтобы получить работающий сервер.

При установке можно сразу создать первого клиента. Установщик добавит его в поддерживаемые подключения и покажет персональную HTTPS-ссылку подписки, которую можно импортировать в совместимое приложение.

## Дополнительные подключения

В четвёртом вопросе установщика можно выбрать **Y**, чтобы увидеть дополнительные варианты. Каждый настраивается отдельно:

- **XTLS Vision** - дополнительное подключение VLESS поверх TLS. Нужен **третий домен**, отличный от домена панели и REALITY.
- **WebSocket и Trojan gRPC** - дополнительные варианты транспорта. Выбираются одним вопросом.
- **AmneziaWG 3.1** - отдельное UDP-подключение с собственным клиентом, который создаётся в панели.
- **XHTTP для CDN** - дополнительный профиль, подготовленный для работы через сеть доставки контента (CDN). Создаётся **выключенным**, после чего нужно самостоятельно настроить CDN-провайдера, включить подключение и привязать клиента.

Для первой установки рекомендуем оставить дополнительные подключения выключенными (`N`). Позже можно обдуманно выбрать нужный вариант при новой установке или использовать штатные средства панели с учётом конфигурации проекта.

## Зачем здесь nginx

nginx автоматически выполняет несколько задач:

1. Принимает HTTPS-запросы к панели и подпискам 3x-ui и направляет их на внутренние сервисы.
2. Маршрутизирует входящие TCP-подключения по домену, указанному в TLS.
3. Показывает **сайты-прикрытия** на соответствующих доменах.
4. Работает с HTTPS-сертификатами Let's Encrypt, которые автоматически продлеваются через Certbot без остановки nginx.

Внешние служебные интерфейсы не требуют отдельных открытых портов панели. REALITY маршрутизируется через nginx stream, Hysteria2 использует UDP/443, а HTTP-обработка nginx применяется там, где она нужна. Пользователю не требуется вручную создавать эти конфигурации.

## Что такое подписка

**Подписка** - личная HTTPS-ссылка, по которой приложение получает актуальные параметры твоих подключений. Вместо ручного ввода каждого сервера достаточно добавить её в поддерживаемый клиент.

У проекта есть обычная подписка, формат JSON и поддержка Mihomo/Clash. Доступные форматы зависят от включённых настроек панели. Если меняешь домен или переносишь клиентов на другой VPS, пригодятся руководства по [смене доменов](domains.md) и [Backup](backup.md).

## Каскад из двух VPS

**Твоё устройство → Входной VPS → Выходной VPS → Интернет**

Каскад состоит из двух собственных серверов проекта. Входной принимает соединения клиентов, а выходной направляет их в интернет. Например, можно использовать российский VPS как точку подключения, а сервер в другой стране - для выхода наружу.

Настройка выполняется в пункте **«5. Каскад»**. Управляемый маршрут создаётся без ручного редактирования Xray. На входном сервере Cloudflare WARP необходимо отключить: WARP и каскад используют несовместимые схемы маршрутизации. На выходном сервере WARP допускается.

[Пошаговая настройка каскада](cascade.md) подробно объясняет домены, подготовку обоих VPS, проверку маршрута и отключение.

## Что делает Cloudflare WARP

Для обычного одиночного VPS в русском меню можно выбрать WARP. Установщик добавит выход `warp-masque` и правила маршрутизации российских направлений через Cloudflare. Сайты, попавшие под эти правила, будут видеть выходной IP Cloudflare вместо IP твоего VPS. Другие направления обслуживаются по действующим правилам Xray.

WARP - отдельная маршрутизация сервера; устройство по-прежнему подключается к выбранному профилю 3x-ui.
