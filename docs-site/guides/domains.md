# Смена доменов без переустановки

## Зачем менять домен

Домен панели и домен REALITY привязывают подключения к серверу по понятным именам. Иногда их приходится менять: не удалось продлить регистрацию, старое имя перестало открываться у провайдера или ты решил использовать новый домен.

В 3X-UI AUTO NGINX для этого есть **«2. Смена доменов»**. С помощью отдельной операции можно поменять домен панели, REALITY или оба сразу **с сохранением клиентов, настроек и статистики**, без новой установки сервера.

## Какие домены используются

| Роль | Для чего |
| --- | --- |
| **Домен панели** | Веб-панель 3x-ui, подписки, HTTPS и дополнительные веб-сервисы |
| **Домен REALITY** | Основное REALITY-подключение и связанная с ним конфигурация |
| **Домен Vision** | Необязательное отдельное XTLS Vision-подключение с собственным сертификатом |

Можно поменять домен панели, REALITY или оба. **Домен Vision эта операция не изменяет**: он настраивается отдельно. Все используемые имена должны быть разными.

| Что меняешь | Что потребуется обновить после смены |
|---|---|
| Только панель | Адрес панели, URL подписок и личного DNS; профили, использующие прежний домен панели |
| Только REALITY | Параметры REALITY в клиентских приложениях; подписку обновить, её домен остаётся прежним |
| Оба домена | Адрес панели, ссылки подписок, затронутые профили и личный DNS |

Если VPS служит выходом каскада, после смены доменов проверь межсерверное подключение и при необходимости [переподключи каскад](cascade.md).

## 1. Подготовь новые домены

У тебя должен быть доступ к настройкам DNS новых доменов. Например, если переходишь с `old.example.com` на `panel.example.net`, создай **A-запись** `panel.example.net`, указывающую на IPv4 текущего VPS. Для нового REALITY-домена создай отдельную A-запись на тот же сервер.

Если используются AAAA-записи, они должны указывать на доступный IPv6 этого же сервера. Проверь, что новые имена разрешаются в нужный адрес. **TCP-порт 80** должен быть доступен извне: он используется для выпуска HTTPS-сертификатов.

Прежние домены панели и REALITY к моменту смены могут уже указывать на другой сервер или быть удалены из DNS.

Перед сменой сохрани актуальный Backup вне VPS. Менеджер дополнительно сам создаст полный Backup v3 перед изменениями.

## 2. Выполни смену

Подключись к VPS по SSH. Если вошёл под обычным пользователем, сначала выполни `sudo -i`.

На VPS от root запусти менеджер из каталога, где сохранён скрипт:

```bash
bash x-ui-latest.sh
```

Если файла нет, скачай и запусти его:

```bash
curl -fSL https://github.com/xPROMSx/3x-ui-auto-nginx/releases/latest/download/x-ui-latest.sh -o x-ui-latest.sh && bash x-ui-latest.sh
```

Выбери русский язык. Не выбирай пункт «1. Установка» на работающем сервере.

1. Выбери **«2. Смена доменов»**.
2. Выбери нужный пункт: **«1. Изменить домен панели»**, **«2. Изменить домен REALITY»** или **«3. Изменить оба домена»**.
3. Введи подготовленные имена. Сверь показанные старые и новые значения.
4. Для подтверждения введи `YES`. Менеджер создаст Backup, проверит настройки, подготовит сертификаты и обновит конфигурацию. Дождись результата.

## 3. Проверь результат

1. Открой панель по действующему адресу: новому, если менял панель, или прежнему, если менял только REALITY.
2. Если изменился домен панели, замени URL подписок в приложениях на актуальные из панели; обнови личный DNS, если используешь AdGuard Home.
3. Обнови подписки, а если пользовался отдельной ссылкой подключения, заново получи затронутый профиль из панели. Проверь реальное подключение устройства.
4. При использовании каскада проверь состояние и внешний IP.

Если всё работает, смена завершена.

## 4. Что сохраняется

Смена доменов - это **изменение работающей установки**, а не её замена. Проект сохраняет клиентов, учётные данные, правила и статистику; меняются только связанные с доменами управляемые настройки и сертификаты.

При смене домена панели меняется и адрес личного DNS; для DoT обновляется сертификат.

### Если старый домен заблокировали

Выполни обычную смену доменов по этой инструкции. Доступ к старому домену не требуется, если локальный стек исправен.

### Если не удалось продлить домен

Используй новые домены. Если меняется домен панели, сообщи пользователям новый URL подписки: старая ссылка сама не изменится.

## 5. При ошибке

Менеджер проверяет изменения перед применением и сохраняет Backup и информацию для восстановления. Если появилось сообщение `ROLLBACK_UNVERIFIED`, останови дальнейшие изменения: не удаляй Backup и данные восстановления, сохрани точный текст ошибки и сначала проверь состояние сервера.

**Не используй «1. Установка» для исправления ошибки смены доменов.** Установка заменяет управляемые данные. Раздел изменения доменов рассчитан именно на работающий стек.
